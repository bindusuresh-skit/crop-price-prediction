# Crop Price Prediction

## 📌 Project Overview

Crop Price Prediction is a machine learning-based application that predicts crop prices using historical agricultural data. The project provides an interactive dashboard where users can select crop-related information and get price predictions.

## 🎯 Objectives

- Predict crop prices using historical data.
- Analyze agricultural price patterns.
- Provide an easy-to-use interactive dashboard.
- Help users understand estimated crop prices.

## 🚀 Features

- 🌾 Crop price prediction
- 📊 Interactive dashboard
- 📈 Data analysis and visualization
- 🤖 Machine learning-based prediction
- 📁 CSV dataset integration
- 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Plotly
